# AGENTS.md — задача для Codex

## Что это
Веб-приложение Lampa (стоковая версия, файлы `index.html`, `app.min.js`,
`css/app.css`, `vender/`) + светлая тема в файлах `redesign.css`
и `redesign.js`, подключённых из `index.html`. Тема уже работает
(версия 6), задача — довести её до ума.

## Цель
Светлая цветовая схема в духе референса Flix.id: мягкий голубовато-серый
фон, тёмный текст, оранжевый акцент рейтингов, полупрозрачное белое
стекло на панелях (настройки, модалки, списки). Всё должно читаться
на всех экранах: главная, карточка фильма, настройки, уведомления,
поиск, списки. Плеер не трогать.

## Жёсткие правила
- **Вёрстка оригинала НЕ меняется.** Боковое меню, ряды, карточки,
  настройки — на штатных местах и штатных размеров. Только цвет.
- **Не трогать `app.min.js` и `css/app.css`.** Все изменения — только
  в `redesign.css` и `redesign.js`. Оригинальные файлы — эталон.
- **DOM не перестраивать.** Никаких перемещений узлов, никаких новых
  баннеров и навигаций. Только CSS-правила поверх и классы на body.
- Перед правкой экрана найди его селекторы в `css/app.css` (файл большой,
  ищи по имени блока: `.menu`, `.items-line`, `.card`,
  `.full-start-new`, `.settings`, `.modal`, `.notice`).
- Осторожно с наследованием цвета: `body { color }` протекает во все
  элементы без явного цвета — тёмный текст на тёмных поверхностях
  (фото карточки, шторки) становится невидимым. Проверяй каждый экран.
- Шрифт не менять, только цвета.

## Текущее состояние (v6)
- `redesign.js` только вешает на body классы `redesign` и `light--version`
  (второй отключает тёмные правила стока с `:not(.light--version)`).
- `redesign.css` — светлый фон, тёмный текст и иконки в меню и шапке,
  оранжевые рейтинги, полупрозрачные настройки/модалки/списки,
  приглушённый фон карточки (backdrop 0.15, постер на мобиле 0.3).
- Известные недоделки на момент передачи: кнопка «Назад» в нижней
  мобильной панели требует перепроверки на телефоне (в десктопном
  браузере такой кнопки нет, возврат стрелкой сверху работает).

## Как проверить
В корне репозитория: `python3 -m http.server 8000`, открыть
`http://localhost:8000/` в браузере. Проходить приветствие не нужно,
если профиль уже создан. Проверять: главную, карточку фильма,
настройки, уведомления (колокольчик), поиск. Для мобильного вида —
узкий viewport.
